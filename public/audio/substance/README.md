# Substance 오디오 샘플 (하이브리드 엔진)

이 폴더에 아래 4개 CC0 오디오 파일을 넣으면 사운드 엔진이 자동으로 사용한다.
**없으면 합성(synth)으로 폴백**하므로 비어 있어도 페이지는 정상 동작한다.

| 파일명 | 성격 | 길이 | CC0 검색어 |
|--------|------|------|-----------|
| `bubbling-underwater.mp3` | 수중 점성 기포 (루프) | 5s+ | `underwater bubbles`, `viscous bubbling`, `hydrophone` |
| `injection-disperse.mp3` | 주사액이 물에 퍼짐 | 2~4s | `ink in water`, `liquid dispersion`, `underwater whoosh` |
| `membrane-stretch.mp3` | 끈적한 막 늘어남 | 1~1.5s | `wet squelch`, `slime stretch` |
| `division-splat.mp3` | 습하고 육중한 파열 | ~0.3s | `wet splat`, `flesh impact`, `squish burst` |

## 영화 레퍼런스 (동일 질감을 위한 후처리 팁)

영화팀은 화산 녹음·청진기 내장음 등을 **타임스트레치(Paul Stretch)** 로 늘려 점성을 만들었다.
샘플이 너무 "깨끗"하면 살짝 느리게(피치 다운) + lowpass로 먹먹하게 하면 더 근접한다.
