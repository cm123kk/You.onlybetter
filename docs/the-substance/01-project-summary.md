# THE SUBSTANCE — 랜딩페이지

> The only thing money has never been able to buy — until now.

영화 《The Substance》(2024, dir. Coralie Fargeat)에 등장하는 가상의 블랙마켓 제품을, 실제로 판매하는 익명 서비스의 랜딩페이지로 재해석하는 디자인 사이드 프로젝트.

---

## 배경 및 목적

### 왜 만드는가

- **원재료의 완성도**: 영화 자체가 커스텀 서체, 로고 심볼(◗◗), 보이스오버 스크립트, 컬러 언어, 제품 메커니즘까지 완결된 브랜드 시스템을 이미 갖추고 있음. 코드를 쓰기 전부터 브랜드 자산이 존재하는 희귀한 조건.
- **디자인 실험의 무대**: 일반적인 세일즈 랜딩페이지 문법을 뒤집는 실험 — "설득하는 페이지"가 아니라 "선택하는 페이지". 정보를 더 줄수록 신뢰가 쌓이는 통념을, 정보를 감출수록 욕망이 커지는 구조로 반전.
- **몰입형 인터랙션 포트폴리오**: 스크롤 기반 텍스트 리빌, Canvas 세포 분열, SVG 모핑, Web Audio 합성 사운드 등 순수 구현 기술을 하나의 서사 안에서 통합 시연.

### 기대 효과

- 영화의 시청각 언어(컬러 아크, 타이포, 사운드 시그니처)를 웹 인터랙션으로 번역한 레퍼런스 케이스 확보
- "Temptation Architecture"(유혹의 설계) — 심리 기반 UX 원칙을 실제 화면으로 검증
- 브랜드리스(brandless) 아이덴티티 — 이름·회사·주소 없이 심볼 하나로 성립하는 디자인 실험

## 핵심 기능

우선순위 순.

| # | 기능 | 설명 | 우선순위 |
|---|------|------|---------|
| 1 | 스크롤 인트로 시퀀스 | 활성화 스크립트가 스크롤에 따라 한 줄씩 리빌되는 풀뷰포트 오프닝 | 필수 |
| 2 | 6개 서사 섹션 | HERO → THE SUBSTANCE → THE PROTOCOL → THEY KNOW → ACCESS → FOOTER 정적 레이아웃 | 필수 |
| 3 | 살아있는 배경 레이어 | 세포 분열 파티클 · 계란 노른자 모핑 · 형광 액체 출렁임 (동시 작동) | 필수 |
| 4 | 컬러 아크 애니메이션 | 스크롤 진행에 따라 옐로(#F5E642, 원본 자아) → 그린(#AAFF00, 활성화)으로 전환 | 필수 |
| 5 | 인터랙션 스테이트 | 로고 분리 / 키워드 pulse glow / CTA 반전 / 면책조항 페이드아웃 / Phase 03 잠금 | 필수 |
| 6 | 최종 CTA — 지원 폼 | "구매"가 아닌 "고려 요청(Request Consideration)" — 이메일 입력 1개 | 필수 |
| 7 | Web Audio 사운드 레이어 | 880Hz 딩~, 40Hz 드론, 세포 버블링 등 완전 합성. 우측 하단 토글, 기본 OFF | 필수 |
| 8 | 영화 기법 시각 번역 | 매크로→풀아웃, 대칭 붕괴, 과잉조명 플래시 등 촬영 기법의 CSS 번역 | 필수 |

> **모든 기능은 필수다.** 이 페이지의 존재 이유는 "영화 같은 시청각 경험의 극대화"이다. 사운드와 영화 기법 번역은 부가 장식이 아니라 핵심 경험 그 자체 — 시각(컬러 아크·배경 생명체·매크로 렌즈)과 청각(딩~·유기적 드론·세포 사운드)이 스크롤 서사와 한 몸으로 작동해야 완성된다.

## 대상 사용자

### 페르소나 — "The Desperately Polished"

- **시장**: 북미 · 유럽
- **연령**: 50–90세 (나이가 많을수록 욕망이 절박)
- **정체성**: 임원 · 셀럽 · 상속인 · 프라이빗 클리닉 단골
- **상태**: 보톡스, 필러, 줄기세포, NAD+, Senolytics — 다 해봤음. 다음 단계가 없던 사람.
- **트리거**: 허영이 아니라 "거울보다 사진이 더 두려워진 순간"
- **자기합리화**: "이건 그냥 최적화야." — 알면서도 한다. 그게 포인트.

### 세부 유형

- **The Executive** — 방 안에서 가장 나이 든 사람이 되어간다는 감각
- **The Talent** — 카메라 앞에서 세상이 다르게 반응하기 시작한 사람
- **The Heir** — 다 살 수 있지만 거울 앞에서는 살 수 없는 것이 있음을 아는 사람

> 실제 사용자는 이 페르소나가 아니라 **디자인·인터랙션 감상자**(포트폴리오 관람자)이나, 모든 카피·비주얼 결정은 위 페르소나를 향해 설계된다.

## 브랜드 3원칙 (모든 결정의 기준)

| 원칙 | 의미 | 디자인 반영 |
|------|------|------------|
| **Anonymity** (익명성) | 이름·회사·창립자·주소 없음. ◗◗ 심볼이 유일한 아이덴티티 | 워드마크 없음, 심볼 단독 사용 |
| **Irreversibility** (불가역성) | 되돌릴 수 없음. "There's no going back"은 경고가 아니라 유혹 | 반복되는 영구성 카피, 되돌릴 수 없는 인터랙션 |
| **Imbalance** (불균형) | 균형을 약속하지만 집착을 배달. 정보를 숨김 | 잠긴 Phase 03, 사라지는 면책조항, 희박한 정보 |

### Temptation Architecture — 핵심 메커니즘

세일즈 페이지가 아닌 심리적 설계. 5원칙:

1. **정보 결핍** — 더 알고 싶게, 더 적게 준다
2. **증거 없는 확신** — 증언에 이름·직업 없음, 나이만
3. **거절 불안** — 구매가 아니라 "지원". 거절 가능성이 긴박감을 만든다
4. **경고가 유혹이 됨** — "Results vary. Irreversible."이 가장 강력한 카피
5. **영구성을 통한 헌신** — "There's no going back" 반복

## 기술적 범위

### 포함

- 6개 섹션 + 스크롤 인트로의 단일 페이지(single-page) 랜딩
- 스크롤 기반 순차 텍스트 리빌
- Canvas 세포 분열 / SVG 노른자 모핑 / 형광 액체 배경 애니메이션
- 스크롤 연동 컬러 아크 (옐로 → 그린)
- 전체 인터랙션 스테이트 (hover, 잠금, 페이드)
- Web Audio API 완전 합성 사운드 (오디오 파일 없음)
- 모바일 반응형 대응

### 제외

- 실제 결제 / 커머스 기능 (가격 없음 — "Investment discussed upon selection")
- 백엔드 · 폼 실제 전송 처리 (이메일 입력은 UI 시연 수준)
- 회원가입 · 로그인 · 계정 시스템
- 다국어 (영문 카피 원문 유지 — 서사의 일부)
- CMS · 콘텐츠 관리 (콘텐츠 전량 고정)

### 제약사항

- **타이포그래피**: 영화 커스텀 서체는 상업적 구매 불가 → 1순위 Dharma Gothic Condensed ExBold(Adobe Fonts), 대안 Bebas Neue(무료). ALL CAPS 전용, 자간 -0.03em, 폰트 혼용 없음
- **컬러**: 5색 고정 팔레트 엄수 (배경 #0A0A0A / 표면 #F5F5F0 / 심볼 #F5E642 / 액체 #AAFF00 / 결과 #C41E3A). 임의 색상 금지, 레드는 극소량만
- **사운드**: 오디오 파일 사용 금지 — 전량 Web Audio API 실시간 합성. AudioContext는 사용자 제스처 이후에만 시작(브라우저 정책)
- **레이아웃**: 단일 센터 컬럼, max-width 680px. 스크롤 인트로 캔버스만 full-bleed. 압도적 여백 유지
- **톤앤매너**: 차갑고 단정하고 익명적. 따뜻함·사과 없음. 설명하지 않고 선언한다
- **저작권**: 영화 원작 오마주 — 푸터에 출처 명시, "가상 개념 / 실제 제품 아님 / 의학적 주장 없음" 면책조항 필수

## 성공 기준

- **시청각 증폭 (최우선)**: 영화를 본 사람이 "이건 영화 그 자체다"라고 느낄 만큼 시각(컬러 아크·살아있는 배경·매크로 렌즈 번역)과 청각(딩~·유기적 드론·세포 사운드)이 극대화되어 있는가. 소리를 켠 순간 경험의 밀도가 완전히 달라지는가
- **몰입감**: 방문자가 "판매 페이지"가 아니라 "발견한 무언가"로 느끼는가
- **서사 완결성**: 스크롤 시작부터 CTA까지 옐로→그린 컬러 아크가 감정선(엘리자베스→수)을 재현하는가
- **불안의 설계**: 정보 결핍·잠금·페이드가 편안함이 아닌 긴장을 유발하는가
- **기술 통합**: 스크롤·Canvas·SVG·Web Audio가 서사를 방해하지 않고 하나로 작동하는가
- **브랜드리스 성립**: 이름 없이 심볼 ◗◗ 하나로 아이덴티티가 성립하는가
